# Loan Approval Prediction System

## About the Project

This project predicts whether a loan application should be approved or rejected.

The prediction is made using information about the applicant such as income, education, employment status and credit history.

## Objective

The main aim of this project is to automate the loan approval prediction process.

## Dataset

The dataset contains information such as:
- Gender
- Married
- Dependents
- Education
- Self Employed
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area
- Loan Status

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Joblib

## Machine Learning Models

The following models were used:
- Logistic Regression
- Decision Tree
- Random Forest
- Naive Bayes
- Support Vector Machine

## Steps

1. Loaded the loan dataset
2. Checked the data
3. Handled missing values
4. Converted categorical values into numbers
5. Performed data analysis
6. Selected the required features
7. Split the data into training and testing data
8. Trained different machine learning models
9. Compared the models
10. Predicted loan approval
11. Saved the best model

## Result

The models were compared using accuracy, precision, recall and F1-score.

## Conclusion

This project shows how machine learning can be used to predict loan approval based on applicant information.
